# ระบบติดตามการใช้ประโยชน์วัสดุเหลือใช้ทางการเกษตร (Agri By-product Management, ABM) 1.8.1

ระบบของ**เจ้าหน้าที่และผู้บริหาร** สำนักงานเกษตรจังหวัดกำแพงเพชร: บันทึกการจัดการวัสดุเหลือใช้ทางการเกษตรรายแปลงพร้อมภาพ เป้าหมายรายอำเภอ ก๊าซเรือนกระจกที่ลดได้ มูลค่า รายงาน และ Dashboard ผู้บริหาร

- หน้าเว็บ: https://krit-pj.github.io/KPP-Agri-Byproduct-Management/
- หน้าเจ้าหน้าที่: `admin.html`
- ตลาดสำหรับเกษตรกรและผู้รับซื้อ: **Green Gain Hub** https://krit-pj.github.io/Green_Gain_Hub-KPP/ (คนละระบบ)

## ใหม่ในรุ่น 1.8.1 (28 พ.ย. 2569) — จุดรับซื้อหลายวัสดุและหน่วยราคา (คู่กับ Green Gain Hub 4.3.0)

- อ่านคอลัมน์ X `Price_Unit` และ Y `Materials_JSON` ของผู้รับซื้อจาก feed (แถวเก่าอ่านเป็นวัสดุเดียว บาท/ไร่)
- สรุปรายวัสดุ: จุดรับซื้อนับในทุกวัสดุที่รับซื้อ · ราคาเฉลี่ยเป็นบาท/ไร่ (บาท/ตัน × BioRate = ประมาณการ, บาท/ก้อน ไม่นำมาเฉลี่ย) · `priceByUnit` แสดงราคาตามหน่วยที่ผู้รับซื้อระบุ (Dashboard ชี้ที่แถบวัสดุ)
- รายงาน "รายการจุดรับซื้อ": แสดงทุกวัสดุพร้อมราคาและหน่วย

## ใหม่ในรุ่น 1.8.0 (28 พ.ย. 2569) — สูตรคำนวณชีวมวลและก๊าซเรือนกระจก

- **ชีวมวลต่อไร่ = อัตราชีวมวลต่อผลผลิต (ตันชีวมวล/ตันผลผลิต) × ผลผลิตเฉลี่ย (ตัน/ไร่)** ตามข้อมูล สกว. ในเอกสารเป้าหมายปีงบประมาณ 2570 (เลือกได้ต่อพืช: อัตรา × ผลผลิต หรือกำหนดเป็นตัน/ไร่)
  - ข้าว (ฟางข้าว) 1.522 × 0.613 = 0.933 · อ้อย (ยอดและใบ) 0.153 × 9.746 = 1.491 · ข้าวโพด (ต้น ยอด ใบ) 1.245 × 0.822 = 1.023 ตัน/ไร่ (เดิม 0.75 / 0.23 / 0.83)
  - เพิ่ม **สัดส่วนน้ำหนักแห้ง** ต่อพืช (ค่าเริ่มต้น 1.0 = ถือว่าค่า สกว. เป็นน้ำหนักแห้ง ปรับได้เมื่อยืนยัน)
- **ก๊าซเรือนกระจกคิดจากชีวมวลเดียวกัน:** พื้นที่ × ชีวมวลต่อไร่ × สัดส่วนน้ำหนักแห้ง × Cf × EF รวม ÷ 1,000,000 (เดิมใช้ค่ามาตรฐาน IPCC Table 2.4 คนละฐานกับตัวเลขชีวมวล ยังเลือกกลับได้ในค่าคงที่)
- **เมนู ตั้งค่า → สูตรคำนวณชีวมวลและก๊าซเรือนกระจก** (Mini Super Admin / Super Admin): สูตรพร้อมตัวอย่างคำนวณทีละขั้น, ตารางค่าตามพืช, แก้ค่า (อัตรา ผลผลิต สัดส่วนแห้ง Cf แหล่งอ้างอิง), **นำเข้าจาก Excel** (รูปแบบเอกสาร สกว. หรือไฟล์ที่ดาวน์โหลดจากระบบ แสดงค่าเดิม/ใหม่ก่อนยืนยัน), **ดาวน์โหลดค่าปัจจุบัน**, **ประวัติชุดค่าและย้อนกลับ** (ชีต `ghg_history`) — ไม่ได้เปิดให้พิมพ์สูตรอิสระ เพื่อกันสูตรผิดและตรวจสอบย้อนหลังได้
- ตัวเลขทุกรายการคำนวณใหม่ตามชุดค่าปัจจุบัน (รวมรายการเดิม) เลขชุดค่าแสดงในหน้าวิธีคำนวณและรายงาน
- Apps Script 1.8.0: `Ghg.gs` `Residue.gs` `Admin.gs` `Code.gs` — หลัง deploy การเรียกครั้งแรกจะ (1) เพิ่มคอลัมน์ `Biomass_Method` `RPR_t_t` `Yield_t_rai` `DMF` ในชีต `ghg_crops` (2) สร้างชีต `ghg_history` และเก็บค่าเดิม (3) ใส่ค่า สกว. และเปลี่ยนฐาน GHG — ครั้งเดียว (Script Property `GHG_BIOMASS_V180`) ย้อนกลับได้จากประวัติ

## ใหม่ในรุ่น 1.6.0 (28 พ.ย. 2569) — หน้าเว็บเท่านั้น ไม่ต้อง deploy Apps Script

- **การ์ดข้อมูลจังหวัด (C-1) รวมเป็นแผงเดียว** สูงจากเดิมราว 450 px เหลือราว 200 px: ตัวเลข 3 ตัวอยู่ในแถบเดียวคั่นด้วยเส้นบาง, ประเภทการจัดการเป็นปุ่มเม็ดยาแถวเดียว (กดกรองทั้งหน้าเหมือนเดิม ประเภทที่เป็น 0 แสดงจาง), ความคืบหน้าเทียบเป้าอยู่หัวแถวประเภท, บรรทัด "ทุกอำเภอ ปีงบประมาณ …" ที่ซ้ำกับช่องเลือกเอาออก (แสดง "กำลังกรอง: …" + ล้างตัวกรอง เฉพาะเมื่อกรองพืช/ประเภท) — แท็บการเพาะปลูกและตลาดใช้แถบตัวเลขเดียวกัน
- **การแสดงผลแบบคลิปตัวอย่าง:** เปลี่ยนแท็บแล้วเนื้อหาเบลอ-จางเข้า, ตัวเลขนับขึ้นสู่ค่าใหม่, แถบและแท่งกราฟยืดออก, แผงกระจกฝ้าเบา ๆ บนพื้นไล่สีเขียวอ่อน (คงสีเขียวของกรมและตัวอักษรเข้ม) ทั้งหมดไม่เกิน ~0.5 วินาที และปิดเองเมื่อเครื่องตั้งค่า "ลดการเคลื่อนไหว"
- มือถือ: หน่วยอยู่บรรทัดใต้ตัวเลขด้วยตัวเล็ก หน่วยก๊าซเรือนกระจกยังเป็นคำไทยเต็ม

## ใหม่ในรุ่น 1.5.0 (26 พ.ย. 2569)

- **ชื่อระบบใหม่:** ระบบติดตามการใช้ประโยชน์วัสดุเหลือใช้ทางการเกษตร (เดิม ระบบบริหารจัดการวัสดุเหลือใช้ทางการเกษตร) ทั้งหน้าเว็บ หน้าเจ้าหน้าที่ และชื่อรายงานจาก Apps Script
- **หัวเว็บเดียวกันทุกหน้า:** โลโก้ ชื่อระบบ และคำอธิบายด้านซ้าย ปุ่ม "ตลาด Green Gain Hub" และ "เข้าสู่ระบบเจ้าหน้าที่" ด้านบนขวา หน้าเจ้าหน้าที่มีปุ่ม **หน้าหลัก** และแถบผู้ใช้ใต้หัวเว็บ (คำอธิบายซ่อนบนมือถือ)
- **หน้าแรก (ผลการจัดการ):**
  - เอาการ์ด "ผลการดำเนินงานลดการเผา" และการ์ดใหญ่ "พื้นที่จัดการ เทียบเป้าหมาย" ออก ผลรวมเทียบเป้าย้ายเป็นการ์ดแรก "รวมทุกประเภท (ไร่)" ในแถววิธีจัดการ
  - การ์ด 3 ใบ: ลดก๊าซเรือนกระจกลงได้ · ปริมาณชีวมวลที่จัดการได้ · คิดเป็นมูลค่า (ป้าย "ประมาณการ" และวิธีคิดอยู่ในปุ่ม ⓘ)
  - แถว **พื้นที่จัดการแยกตามประเภท** อยู่ใต้การ์ด 3 ใบ เหนือแผนที่ แต่ละการ์ดแสดงชื่อ (ไร่) และตัวเลข **กดการ์ดเพื่อกรองทั้งหน้า**: การ์ด 3 ใบ ไอคอนพืช แผนที่ อันดับอำเภอ ตารางรายอำเภอ และแถบ "เทียบกับพื้นที่เก็บเกี่ยว"
  - แถบ "วัสดุเหลือใช้ทางการเกษตรที่จัดการได้ เทียบกับพื้นที่เก็บเกี่ยว" ตามตัวกรองอำเภอ พืช และวิธีจัดการ (พื้นที่เก็บเกี่ยวจากแถว อำเภอ × พืช ของ balance)
- **หน้าเจ้าหน้าที่:**
  - เมนู: บันทึกวัสดุเหลือใช้ทางการเกษตร · สรุปผลการส่งเสริม · ออกรายงาน (โครงสร้างเมนูเดิม)
  - ฟอร์มบันทึก 4 ขั้น (สถานที่และวันที่ → ชนิดพืชและวิธีจัดการ → ขนาดพื้นที่ → หลักฐาน) ข้อมูลเพิ่มเติมพับไว้ ใช้คำภาษาไทยแทนศัพท์เทคนิค กล่อง "ตรวจสอบก่อนบันทึก" อยู่ข้างฟอร์ม (ชื่อช่องและ API เดิม)
  - สรุปผลการส่งเสริม: ตัวเลขรวม 5 ช่อง และพื้นที่แยกตามวิธีจัดการ/ชนิดพืช ก่อนรายการบันทึก
  - ออกรายงาน: แบบใหม่ **สรุปผู้บริหาร (1 หน้า)** เป็นค่าเริ่มต้น (`residue.exec`, `residue.execmethods`) ตัวเลขสำคัญ 5 ช่อง อำเภอเรียงจากร้อยละของเป้าต่ำสุด ช่องว่างจากเป้า และพื้นที่เก็บเกี่ยวที่ยังไม่มีบันทึก แบบเดิมอยู่ใต้ "รายงานอื่น"
- Apps Script 1.5.0: `Code.gs` (APP_NAME, APP_VERSION) `Reports.gs` (แบบรายงาน summary) `Residue.gs` (ส่วน residue.exec / residue.execmethods) `Ggh.gs` (ชื่อระบบ) — ต้อง deploy เวอร์ชันใหม่ (ดู DEPLOY_NOW.md) จนกว่าจะ deploy หน้าเว็บยังใช้ได้ แต่ยังไม่มีแบบรายงานสรุปผู้บริหาร

## ทำไมแยกจาก Green Gain Hub (19 พ.ย. 2569)

ผู้ใช้มี 2 กลุ่มที่ต้องการคนละอย่าง

| | Green Gain Hub | ABM (ระบบนี้) |
| --- | --- | --- |
| ผู้ใช้ | เกษตรกร ผู้รับซื้อ | เจ้าหน้าที่ ผู้บริหาร |
| หน้าที่ | ประกาศขาย หาจุดรับซื้อ แผนที่จับคู่ | บันทึกผล เป้าหมาย GHG มูลค่า รายงาน Dashboard |
| เจ้าของข้อมูล | แปลงประกาศขาย ผู้รับซื้อ บัญชีเกษตรกร/ผู้รับซื้อ | บันทึกการจัดการ ภาพ เป้าหมาย ค่าคำนวณ บัญชีเจ้าหน้าที่ ข้อมูลการเพาะปลูก |

ABM อ่านข้อมูลตลาดจาก Green Gain Hub ผ่าน feed ฝั่ง Server (ไม่คัดลอกมาเก็บ) เพื่อแสดงในแท็บตลาด สมดุลวัสดุ รายงาน และให้เจ้าหน้าที่เลือกผู้รับซื้อตอนบันทึก

## การเข้าสู่ระบบ (คงเดิมจาก Green Gain Hub 2.4.x)

- เจ้าหน้าที่ (Admin): เบอร์โทรอย่างเดียว ผ่านตัวตนกลาง Agri-Risk Map (ตั๋วสำหรับ `ABM` เท่านั้น) เบอร์เดียวใช้ได้ทุกระบบที่เชื่อมโยง ถ้าตัวตนกลางใช้ไม่ได้จะใช้การเข้าสู่ระบบด้วยเบอร์แบบเดิม (`SSO_MODE` = optional)
- Mini Super Admin / Super Admin: ชื่อผู้ใช้ + รหัสผ่านของระบบนี้ (บัญชีเดิมย้ายมาทั้งหมด รหัสผ่านเดิมใช้ได้)
- ลงทะเบียนเจ้าหน้าที่ใหม่ได้ที่หน้าแรก (ปุ่ม "เข้าสู่ระบบเจ้าหน้าที่" → ลงทะเบียน) หรือลิงก์ `#staff-register`

## ความเป็นส่วนตัว

- API สาธารณะเป็นตัวเลขรวมเท่านั้น ไม่มีชื่อ เบอร์ หรือพิกัดรายแปลง
- feed จาก Green Gain Hub เป็น Server ถึง Server ข้อมูลส่วนบุคคลใช้เฉพาะในรายงานของเจ้าหน้าที่ (เบอร์ถูกปิดบังเป็นค่าเริ่มต้น) และรายชื่อผู้รับซื้อตอนบันทึก (ไม่มีเบอร์)
- ภาพอยู่ในโฟลเดอร์ Drive ส่วนตัว เปิดผ่านหน้าเจ้าหน้าที่ตามสิทธิ์อำเภอ
